RAG 知识库功能文档

项目名称：本地知识库智能助手 (Agent Demo)

本系统基于 Spring AI 框架，集成本地知识库 RAG（检索增强生成）能力。
知识文档保存在 D:/agent/docs 目录中，系统启动时自动扫描 .md 和 .txt 文件，
将内容按段落智能分块后，调用 text-embedding-v4 模型（通过阿里云 DashScope 兼容 API）生成向量，
并写入 Chroma 向量数据库。

=== 系统架构 ===

整体流程：用户提问 → RAG 知识检索 → 决策引擎 (Plan → ReAct → Reflect) → 流式返回结果

1. AgentService 接收用户请求后，先调用 LocalRagService 进行知识库检索
2. 检索结果作为上下文拼入用户消息（增强提示词）
3. 增强后的消息交给 DecisionEngine 进行智能推理
4. DecisionEngine 内部执行：TaskPlanner 规划 → ReActExecutor 执行 → ResultReflector 反思

=== RAG 模块详解 ===

【文档扫描与索引】
- 文档目录：D:/agent/docs
- 支持格式：.md、.txt
- 启动时自动索引（agent.rag.auto-index-on-startup=true）
- 使用清单文件（rag-manifest.json）记录已索引文档的路径、大小、修改时间
- 增量更新机制：仅重新索引发生变化的文档，未修改的文档自动跳过
- 删除的文档对应的向量块也会自动清理

【智能分块策略】
- 分块大小：900 字符（agent.rag.chunk-size）
- 块间重叠：120 字符（agent.rag.chunk-overlap）
- 优先在段落边界（双换行）处切割
- 其次在单换行处切割
- 保证语义连贯性，避免句子被截断

【向量化与存储】
- Embedding 模型：text-embedding-v4
- Embedding 服务：阿里云 DashScope 兼容 API（base-url: https://dashscope.aliyuncs.com/compatible-mode/v1）
- 向量数据库：Chroma（默认连接 http://localhost:8000）
- 集合名称：agent_docs
- 批量写入：每批 20 条（agent.rag.batch-size），避免一次性写入过多数据
- 块 ID 使用 MD5(source路径#块序号) 生成，保证唯一性

【相似度检索】
- 检索数量：Top-5（agent.rag.top-k=5）
- 最低相似度阈值：0.0（agent.rag.min-score，开发阶段关闭过滤）
- 返回结果包含：来源文件路径、分块序号、文本内容、相似度分数
- 检索失败时优雅降级，返回空列表，不影响正常对话

=== API 接口 ===

基础路径：/api/rag

1. POST /api/rag/index —— 增量索引（仅处理新增和修改的文档）
2. POST /api/rag/reindex —— 全量重建索引（清空后重新索引所有文档）
3. GET /api/rag/search?query=关键词 —— 测试向量检索

=== 数据存储分工 ===

- 原始知识文档 → D:/agent/docs（文件系统）
- 文档向量数据 → Chroma 向量数据库（agent_docs 集合）
- 会话记录（会话 ID、用户消息、助手回复）→ MySQL 数据库
- 索引清单 → D:/agent/docs/rag-manifest.json

=== 配置项说明 ===

所有 RAG 配置以 agent.rag 为前缀，在 application.yml 中设置：
  enabled: true                     # 是否启用 RAG
  docs-path: D:/agent/docs          # 知识文档目录
  manifest-path: D:/agent/docs/rag-manifest.json  # 索引清单路径
  chunk-size: 900                   # 分块大小（字符）
  chunk-overlap: 120                # 块间重叠（字符）
  top-k: 5                          # 检索返回条数
  min-score: 0.0                    # 最低相似度阈值
  rebuild-on-startup: false         # 是否每次启动全量重建
  auto-index-on-startup: true       # 是否启动时自动索引
  batch-size: 20                    # 向量库批量写入大小
  extensions: [.md, .txt]           # 支持索引的文件格式

=== LLM 对话配置 ===

- 对话模型：deepseek-chat（通过 DeepSeek API，base-url: https://api.deepseek.com）
- 温度参数：0.7
- 系统提示词由 DecisionEngine 内部的 DecisionPrompts 管理
