RAG 功能测试文档

项目名称：本地知识库智能助手

这个系统用于测试 Spring AI 与 Chroma 向量数据库的 RAG 检索能力。
知识文档保存在 D:/agent/docs 目录中，系统会读取 txt 和 md 文件，将内容分块后调用 text-embedding-v4 生成向量，并写入 Chroma 向量数据库。

会话数据不存入向量数据库。
会话 ID、用户消息、助手回复等聊天记录存入 SQL 数据库。
知识库文档内容经过向量化后存入 Chroma。

测试规则：
1. 如果用户询问“知识文档存在哪里”，答案应该是：原始知识文档保存在 D:/agent/docs。
2. 如果用户询问“向量数据存在哪里”，答案应该是：文档分块向量化后存入 Chroma 向量数据库。
3. 如果用户询问“会话 ID 存在哪里”，答案应该是：会话 ID 和聊天消息存入 SQL 数据库。
4. 如果用户询问“当前测试文档的项目名称是什么”，答案应该是：本地知识库智能助手。
5. 如果用户询问“使用的 embedding 模型是什么”，答案应该是：text-embedding-v4。

测试问题示例：
知识文档存在哪里？
向量数据存在哪里？
会话 ID 存在哪里？
当前测试文档的项目名称是什么？
使用的 embedding 模型是什么？
