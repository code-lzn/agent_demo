# Agent 工具模块规划

## 现有能力

| 模块 | 方法数 | 能力 |
|------|--------|------|
| FileTool | 16 | 文件读写、追加、复制、移动、删除、目录创建与删除、元信息、搜索 |
| InputTool | 3 | 键盘打字、组合键（Ctrl+S 等）、切换到应用并输入 |
| ProcessTool | 4 | 启动应用、带参数启动、关闭进程、列出进程 |
| ToolSafety | - | 路径白名单、命令黑名单 |

### 现有短板

1. AI 不知道哪个窗口在前台，无法精确定位操作目标
2. InputTool 逐字符打字，中文/长文本效率极低，没有剪贴板途径
3. 无法执行命令行脚本、获取系统时间、读取环境变量
4. 无法发 HTTP 请求
5. 没有通知能力，任务完成用户不知道
6. 键鼠不分家，有键盘没鼠标不完整

---

## 推荐新增模块（按优先级排序）

### 🔴 第一批：补全桌面自动化闭环

#### 1. WindowTool — 窗口管理

**为什么需要**：InputTool 只能盲打，Agent 不知道打开了什么窗口、不知道谁在焦点。

**依赖**：JNA（Java Native Access）+ Win32 API（`user32.dll`）

**方法设计**：

| 方法 | 功能 |
|------|------|
| `listWindows()` | 枚举所有可见窗口，返回标题 + 句柄列表 |
| `getActiveWindow()` | 获取当前活动窗口标题 |
| `focusWindow(title)` | 按标题或句柄聚焦窗口（`SetForegroundWindow`） |
| `closeWindow(title)` | 关闭指定窗口（`WM_CLOSE`） |
| `minimizeWindow(title)` | 最小化窗口 |
| `maximizeWindow(title)` | 最大化窗口 |
| `resizeWindow(title, w, h)` | 调整窗口大小和位置（`SetWindowPos`） |

**Maven 依赖**：
```xml
<dependency>
    <groupId>net.java.dev.jna</groupId>
    <artifactId>jna</artifactId>
    <version>5.14.0</version>
</dependency>
<dependency>
    <groupId>net.java.dev.jna</groupId>
    <artifactId>jna-platform</artifactId>
    <version>5.14.0</version>
</dependency>
```

---

#### 2. ClipboardTool — 剪贴板操作

**为什么需要**：InputTool 逐字符打字，输入一段中文要几十秒。剪贴板 + Ctrl+V 秒完成。

**依赖**：`java.awt.Toolkit`（JDK 自带，无需额外依赖）

**方法设计**：

| 方法 | 功能 |
|------|------|
| `getClipboard()` | 读取剪贴板文本内容 |
| `setClipboard(text)` | 写入文本到剪贴板 |
| `paste()` | 模拟 Ctrl+V 粘贴 |

> `paste()` 可复用现有 `InputTool.pressKeys("ctrl+v")`。

---

#### 3. SystemTool — 系统操作

**为什么需要**：Agent 经常需要"现在几点了""执行这个脚本看看""当前目录在哪"，目前完全做不到。

**依赖**：JDK 自带

**方法设计**：

| 方法 | 功能 |
|------|------|
| `getCurrentTime()` | 获取当前日期时间 |
| `runCommand(cmd)` | 执行命令行并返回 stdout/stderr |
| `getEnvVar(name)` | 读取环境变量 |
| `getCurrentDir()` | 获取进程当前工作目录 |
| `getSystemInfo()` | CPU 核心数、OS 名称/版本、Java 版本 |

**安全考虑**：`runCommand` 采用**白名单模式**，默认只允许 `dir`、`echo`、`type`、`curl`、`ipconfig`、`ping`、`whoami`、`netstat` 等安全命令。白名单可在配置文件中扩展。

---

### 🟡 第二批：扩展能力边界

#### 4. WebTool — HTTP 请求

**为什么需要**：Agent 无法联网，不能查 API、调接口、获取实时数据。

**依赖**：JDK 自带 `java.net.http.HttpClient`（Java 11+）

**方法设计**：

| 方法 | 功能 |
|------|------|
| `httpGet(url)` | GET 请求，返回状态码 + body |
| `httpPost(url, body, contentType)` | POST 请求 |
| `httpPut(url, body)` | PUT 请求 |
| `httpDelete(url)` | DELETE 请求 |

**安全考虑**：可选 URL 白名单防止 SSRF；限制响应体大小（1MB）防止 OOM。

---

#### 5. NotificationTool — 系统通知

**为什么需要**：Agent 任务跑完后用户不知道，需要主动提醒机制。

**依赖**：JDK 自带 `java.awt.SystemTray`

**方法设计**：

| 方法 | 功能 |
|------|------|
| `notify(title, message)` | 弹出 Windows 托盘通知气泡 |

---

### 🟢 第三批：锦上添花

#### 6. MouseTool — 鼠标控制

**为什么需要**：很多 GUI 操作必须鼠标点击，有键盘没鼠标不完整。

**依赖**：`java.awt.Robot`（JDK 自带）

**方法设计**：

| 方法 | 功能 |
|------|------|
| `getMousePos()` | 获取当前鼠标坐标 |
| `mouseMove(x, y)` | 移动鼠标到指定位置 |
| `mouseClick()` | 左键单击 |
| `mouseRightClick()` | 右键单击 |
| `mouseDoubleClick()` | 双击 |
| `mouseDrag(x1, y1, x2, y2)` | 拖拽 |

---

#### 7. AudioTool — 语音朗读

**为什么需要**：任务完成后语音通知，或者让 Agent "开口说话"。

**依赖**：JDK 自带 `javax.sound.sampled` 或调 PowerShell `Add-Type -AssemblyName System.Speech`

**方法设计**：

| 方法 | 功能 |
|------|------|
| `speak(text)` | 用 Windows TTS 朗读文字 |
| `playSound(filePath)` | 播放音频文件 |

## 补充优化

### ToolSafety 升级

随着工具增多，建议对 ToolSafety 做两处增强：

1. **命令白名单模式**：`SystemTool.runCommand` 采用白名单，和现有黑名单配合生效。白名单在配置文件中通过 `agent.safety.allowed-commands` 配置
2. **URL 安全策略**：为 `WebTool` 增加 URL 白名单支持，复用 ToolSafety 的统一安全框架

### 新增依赖汇总

| 模块 | 新增依赖 |
|------|---------|
| WindowTool | `jna` + `jna-platform` |
| ClipboardTool | 无 |
| SystemTool | 无 |
| WebTool | 无 |
| NotificationTool | 无 |
| MouseTool | 无 |
| AudioTool | 无 |

**只有 WindowTool 需要额外依赖**，其余全部使用 JDK 自带 API。

---

## 实施顺序建议

```
第一轮: WindowTool + ClipboardTool + SystemTool  （补全闭环，零依赖启动）
第二轮: WebTool + NotificationTool                （扩展能力）
第三轮: MouseTool + AudioTool + ToolSafety 升级   （完善细节）
```

---

## 验证方式

1. **单元测试**：每个 Tool 写独立的单元测试（参考 `FileToolTest.java` 的模式）
2. **Swagger 手动测试**：每批新工具写对应的 TestController（参考 `FileToolTestController.java`）
3. **端到端测试**：通过 Chat API 让 Agent 组合使用多个工具完成实际任务，例如：
   - "把桌面上所有 .txt 文件移动到一个新目录里"（FileTool + SystemTool）
   - "查一下 GitHub API 返回的最新 commit，然后写到本地文件"（WebTool + FileTool）
   - "帮我打开记事本，输入当前时间，然后保存"（ProcessTool + WindowTool + ClipboardTool + InputTool）
